# Формат-роутер: три типа постов

Тип поста определяет структуру, разметку и допустимое количество эмодзи. Выбирай тип до написания черновика.

## Алгоритм выбора

1. Это про автора, его опыт, провал или победу? → **Тип 1: личная история**
2. Это факты, наблюдения, выводы, обучение? → **Тип 2: инсайты**
3. Это последовательность действий с результатом? → **Тип 3: шаги**

Смешивать можно осознанно: личный кейс (Тип 1) + вывод отдельным цитатным блоком.

## Тип 1 — личная история / рефлексия

Чистый поток без списков. Читатель проживает историю, а не сканирует её.

- Первая строка — хук: сцена, цифра или признание.
- Абзацы 1–3 строки, пустая строка между ними.
- **Жирный** — только на опорных смысловых точках: хук, поворот, решающее действие (3–5 на пост).
- Подчёркивание — один раз, на главный тезис.
- Эмодзи — максимум 2 на весь пост.
- Финал — вывод или самоирония. Запрещено заканчивать вопросом к аудитории: это фальшивый CTA.

## Тип 2 — инсайты / факты / обучение

Скелет из эмодзи-буллетов, каждый — самостоятельная мысль:

```
🧠 **Ключевая фраза** — пояснение с конкретикой.
⚡ **Вторая мысль** — цифра или пример.
🎯 **Третья мысль** — что это меняет для читателя.
```

- 3–5 буллетов, по одному эмодзи на буллет.
- Ключевая фраза жирным, пояснение обычным.
- Перед буллетами — 1–2 строки контекста, после — вывод.

## Тип 3 — процесс / шаги

Нумерованный список «действие → результат»:

```
1. Сделал X — получил Y
2. Подключил Z — стало быстрее втрое
3. Отказался от W — сэкономил 4 часа в неделю
```

- Каждый шаг — одна строка, глагол первым словом.
- К шагу с затратой добавляй следствие: «серверы жрут 15 000 в месяц и проект не окупается».

## Маппинг на формат доставки

| Тип поста | Обычно хватает | Rich Message оправдан, когда |
|---|---|---|
| Личная история | plain-пост | почти никогда — поток сильнее структуры |
| Инсайты | plain-пост | сравнение → таблица; глубина → details-блоки |
| Шаги | plain-пост | длинный гайд: заголовки, чек-лист, сноски |

Правило: rich-разметка обязана улучшать понимание. Когда сомневаешься — publish plain.
