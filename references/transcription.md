# Транскрибация: TeleTranscribe MCP

Голосовые, подкасты, созвоны и видео превращаются в текст через [TeleTranscribe](https://github.com/AgentSmoki/TeleTransribe) — платформу транскрибации с диаризацией спикеров и word-level таймкодами (ASR GigaAM + pyannote на GPU). Для агента она доступна как MCP-сервер: расшифровка приходит прямо в контекст, без ручного скачивания и локальных моделей.

## Подключение MCP

```bash
claude mcp add --transport http teletranscribe https://mcp.neuroimpuls.ru/mcp
```

API-ключ выдаётся в Telegram-боте TeleTranscribe (@TeleTranscribeBot → Developer API). Баланс проверяется инструментом `check_balance`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `transcribe_file(file_path, speakers)` | локальный аудио/видео файл → текст |
| `transcribe_url(url, speakers)` | ссылка (YouTube, Яндекс.Диск, Google Drive) → текст |
| `transcribe_file_json` / `transcribe_url_json` | то же + word-level таймкоды и диаризация в JSON |
| `dump_telegram_channel(channel, since_days)` | посты канала за период — для анализа контента |
| `dump_youtube_channel(channel_url, since_days)` | видео канала в очередь транскрибации |
| `describe_image(file_path, prompt)` | описание кадра vision-моделью |
| `check_balance()` | остаток баланса |

`speakers=1` — без диаризации (голосовое, монолог); `speakers>=2` — метки SPEAKER_00/01 (интервью, созвон).

## Сценарии в конвейере

**Голосовое → пост.** Автор кидает голосовое файлом:

```
transcribe_file("/path/to/voice.ogg", speakers=1)
→ transcript.md материала → карта фактов → черновик
```

**Интервью/созвон → пост.** Диаризация обязательна — реплики разных людей расходятся по спикерам:

```
transcribe_url("https://youtu.be/VIDEO_ID", speakers=2)
→ в карте фактов помечай, чьё каждое утверждение
```

**Чужое публичное видео → трансформативный пост.** Расшифровка служит сырьём для карты фактов. В пост идут выводы и комментарий автора со ссылкой на оригинал; публикация полного транскрипта чужого материала запрещена.

## Правила работы с транскриптом

- Сырой транскрипт сохраняй в `transcript.md` материала как рабочее доказательство.
- Отделяй утверждения спикера от примеров и оговорок; неуверенно распознанные имена и термины помечай и уточняй у автора.
- Устную избыточность чисти, логику спикера сохраняй.
- Прямой цитатой называй только дословный фрагмент транскрипта; пересказ оформляй как пересказ.
- Приватные куски (имена клиентов, цифры под NDA) помечай в карте фактов как непубликуемые.
