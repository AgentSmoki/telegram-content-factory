# Превью с кастомными Premium-эмодзи

Фирменные кастомные эмодзи (логотипы инструментов, анимированные акценты) делают пост узнаваемым в ленте. Через Bot API бот отправляет кастомные эмодзи только при купленном username на Fragment, поэтому слой построен на userbot: аккаунт автора с Telegram Premium отправляет превью себе в «Избранное» или в превью-чат, автор проверяет рендер и пересылает пост в канал.

## Разовая настройка

1. Получи `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org) → в `.env`:

```
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef...
EMOJI_PREVIEW_CHAT=me
```

2. Установи зависимости эмодзи-слоя: `pip install -r requirements-emoji.txt`
3. Первый запуск любого эмодзи-скрипта создаёт Pyrogram-сессию интерактивно (телефон + код). Файл сессии — секрет: он в `.gitignore`.
4. Установи в аккаунт нужные emoji-паки и выгрузи их document_id:

```bash
python3 scripts/emoji_extract.py
```

5. Перенеси нужные записи из `emoji-extracted.json` в `emoji-catalog.json` (шаблон: `assets/emoji-catalog.template.json`), каждой дай имя, fallback, описание и теги:

```json
{
  "emoji": {
    "brain": {
      "id": "5368324170671202286",
      "pack": "MyPack",
      "fallback": "🧠",
      "desc": "мышление, инсайты, когнитивка",
      "tags": ["мышление", "инсайт", "мозг"]
    }
  }
}
```

## Расстановка маркеров в посте

Агент читает каталог и расставляет маркеры по смыслу (`desc` и `tags`):

- маркер — `[EMOJI:name]`; жирный — `**текст**`; подчёркивание — `<u>текст</u>`;
- эмодзи ставится в начало строки или в финал; середина предложения остаётся чистой;
- максимум 4–5 кастомных эмодзи на пост;
- для записи без числового `id` используй обычный эмодзи-символ (fallback подставится сам).

## Отправка превью

```bash
python3 scripts/emoji_send.py draft.txt
python3 scripts/emoji_send.py draft.txt --chat @my_preview_channel
```

Скрипт заменяет маркеры на entity `MessageEntityCustomEmoji` (offset и length считаются в UTF-16 code units — так требует Telegram), показывает чистый текст в консоли и отправляет в превью-чат.

## Ограничения

- Для рендера кастомных эмодзи получателю нужен любой актуальный клиент; отправителю-userbot — активный Premium.
- Публикация в канал из этого слоя — ручная пересылка автором: превью-чат и канал разделены сознательно, как тест и прод.
- Userbot действует от лица личного аккаунта — используй его только для превью себе, без рассылок.
