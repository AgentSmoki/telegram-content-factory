# Типовые ошибки и их причины

## Валидация

| Симптом | Причина | Что делать |
|---|---|---|
| `тег <div> не входит в Rich HTML` | браузерный HTML вместо Rich HTML | пользуйся тегами из [formatting.md](formatting.md) |
| `в разметке есть, в медиа нет: cover` | tg://-ссылка без объявленного медиа | добавь `--photo cover=файл.jpg` |
| `объявлено, но не используется` | медиа передано, ссылки в тексте нет | убери медиа или вставь `<img src="tg://photo?id=...">` |
| `черновой тег <tg-thinking>` | служебный тег остался в финале | удали тег или валидируй черновик с `--draft` |
| `неподдерживаемые именованные сущности` | `&copy;` и подобные | пиши символ литералом UTF-8 |

## Публикация

| Симптом | Причина | Что делать |
|---|---|---|
| `--confirm-target обязан посимвольно совпасть` | опечатка или другой канал в .env | сверь chat_id: защита работает как задумано |
| `Unauthorized` | битый или отозванный токен | перевыпусти токен у BotFather, обнови .env |
| `chat not found` | бот отсутствует в канале | добавь бота админом с Post Messages |
| `Bad Request: can't parse ...` | серверные правила строже локальных | упрости разметку; сверься с официальной документацией — API развивается |
| Пост виден как «неподдерживаемое сообщение» | старый клиент у читателя | это штатно: публикуй plain/альбом-fallback |

## Эмодзи-слой

| Симптом | Причина | Что делать |
|---|---|---|
| Эмодзи пришёл обычным, без анимации | в записи каталога нет числового `id` | запусти `emoji_extract.py`, перенеси document_id |
| `PREMIUM_ACCOUNT_REQUIRED` | у аккаунта-userbot нет Premium | эмодзи-слой требует активный Premium |
| Скрипт просит телефон и код | первая инициализация Pyrogram-сессии | это разовый вход; файл сессии — секрет |
| `AUTH_KEY_UNREGISTERED` | сессия отозвана (выход со всех устройств) | удали файл сессии, войди заново |
| Сдвинутые offset у entity | длина считалась в символах | считай offset/length в UTF-16 code units — `emoji_send.py` уже делает это |

## Транскрибация

| Симптом | Причина | Что делать |
|---|---|---|
| MCP-инструменты недоступны | сервер не подключён | `claude mcp add --transport http teletranscribe https://mcp.neuroimpuls.ru/mcp` |
| Ошибка баланса | закончились минуты | `check_balance()` → пополни в боте TeleTranscribe |
| Спикеры перепутаны | занижено `speakers` | передай реальное число участников |

## Стилевой гейт

| Симптом | Причина | Что делать |
|---|---|---|
| FAIL на слове, которое автору нужно | встроенный словарь строже голоса автора | добавь слово в `allow_words` профиля |
| Гейт молчит на явном штампе | фразы нет в словарях | добавь в `extra_cliches` или `banned_phrases` профиля |
| Ложный WARN на длину | лонгрид с осознанно длинными абзацами | подними лимиты в профиле проекта |
