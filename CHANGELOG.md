# Changelog

## [0.1.0] - 2026-08-27

### Добавлено

- конвейер источник → пост: идея, голосовое, статья, документ, видео;
- формат-роутер по трём типам постов и батарея хуков четырьмя приёмами;
- редактура в три прохода + детерминированный стилевой гейт `check_style.py`
  со встроенными словарями штампов, канцелярита и AI-конструкций;
- профиль голоса и петля самообучения на памяти правок (`MEMORY.md`);
- офлайн-валидатор Rich HTML по allowlist Bot API 10.3 и браузерное превью;
- публикация Rich Message / plain / альбом с сухим прогоном по умолчанию
  и двойным подтверждением отправки;
- превью с кастомными Premium-эмодзи через Pyrogram userbot;
- транскрибация через TeleTranscribe MCP (диаризация, word-level таймкоды);
- пакет материала `init_material.py`, диагностика `doctor.py`, офлайн-тесты.
